# 13. 서리 유리 스타일 뷰어 UI

상·하단 플로팅 바는 [ImageViewer](https://github.com/edith2580/ImageViewer)의 배치와 동작을 참고해 독립 구현했다. 이번 스타일은 바와 Tab 메타데이터 패널을 옅은 테두리와 어두운 반투명 바탕을 가진 서리 유리처럼 표시한다. **패널 뒤의 뷰어 이미지만 흐려지며**, 버튼·숫자·메타데이터는 흐림 위에 선명하게 표시한다. 바탕화면이나 다른 앱을 캡처하지 않는다.

| 대상 | 구현 |
|---|---|
| Linux (GTK4) | 스크롤 뷰어의 기존 렌더 노드를 패널 경계와 주변 여백으로 제한해 GTK 스냅샷 blur에 합성한다. 네이티브 위젯과 CSS로 전경을 그린다. |
| Windows (Win32) | 패널 뒤 이미지 영역을 작은 GDI 비트맵으로 축소한 후 확대해서 부드럽게 표시한다. 색조와 테두리는 합성하고, 버튼은 네이티브 상태와 이름을 유지한 채 다시 그린다. 메타데이터는 기존 스크롤 가능한 읽기 전용 컨트롤을 유지한다. |

창 크기 변경 중에는 흐림을 잠시 생략하고, 마지막 변경 후 약 120ms 뒤 갱신한다. Windows에서는 가장자리 드래그 중 조작 버튼을 잠시 숨기되 열린 메타데이터는 표시한다. 드래그가 끝나면 이전 고정·표시 규칙을 복원한다. 바의 표시 여부로 이미지 위치나 배율을 바꾸지 않는다. 새 라이브러리나 이미지 리소스를 추가하지 않는다.

이전·다음은 `←`·`→`, 프레임 이동은 `‹`·`›`, 고정은 `◆`·`◇`를 쓴다. 파일·폴더·주소, 번호 이동, 읽기 방향, 오류처럼 기호만으로 의미를 알기 어려운 곳에는 짧은 텍스트를 남긴다. 보조 이름과 툴팁은 상태와 동작을 짧게 설명한다. 원본 이미지 또는 메타데이터는 변경하지 않는다.

## 검증

- Windows: WSL 교차 빌드, PE 시스템 DLL 확인, 실제 Windows에서 바의 흐림 경로, 크기 변경, Tab 메타데이터, 애니메이션, 페이지 탐색 자동 검사 통과.
- Linux: GTK 4.14.5 개발 빌드·Clippy, GTK·공통 Rust 테스트 18개, WSLg Wayland에서 PNG·CBZ 메타데이터(버튼과 키보드), 흐림 노드 생성, 우클릭용 메뉴 표시, GIF 프레임 조작 검사 통과.
- 흐림 렌더 노드가 생성됐다는 사실은 다른 렌더러의 실제 화면 출력이나 성능을 보장하지 않는다. 실제 배포판의 Wayland/X11·DPI·접근성은 [릴리스 전 확인 항목](14-reader-control-layout.md#linux-릴리스-전-확인)으로 남긴다.
