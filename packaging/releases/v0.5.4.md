# nCatImage v0.5.4 — Tab 메타데이터 floating layer

## 변경

- Tab/Shift+Tab의 기존 UI 포커스 이동을 제거하고 **메타데이터 레이어 토글**로 변경했습니다. 기본값은 **꺼짐**입니다.
- 이미지에 포함된 metadata가 있을 때만 이미지 영역 왼쪽 위 floating layer로 표시합니다. 긴 내용은 스크롤하며, metadata 없는 페이지·재열기·오류에서는 이전 내용을 숨깁니다.
- PNG 텍스트/생성 정보·EXIF·XMP·JPEG/GIF 코멘트를 worker에서 bounded 추출합니다. ZIP/CBZ와 animation next/seek에도 연결했습니다.
- GTK/Win32 공통 정책이며 전체 화면·UI 숨김과 독립적입니다. OS modal 대화상자의 Tab 동작은 유지합니다.
- markup으로 실행하거나 원본을 수정하지 않으며 내용을 별도 로그/파일/외부 서버에 저장하지 않습니다.
- 최대 32항목/32KiB, 값당 4096bytes 등 안전 상한이 있습니다. binary ICC 등 모든 metadata 형식을 표시한다는 의미는 아닙니다. [상세 문서](https://github.com/NyarCat/nCatImage/blob/v0.5.4/doc/12-metadata-overlay.md)

**GUI/worker wire v5가 함께 변경됩니다. 구버전 worker와 섞지 말고 실행 중인 앱은 종료 후 새 파일로 다시 실행하세요.**

## 다운로드

- Linux x86_64: `nCatImage-0.5.4-x86_64.AppImage` — Ubuntu 24.04/glibc 2.39 이상 개발 프리뷰.
- Windows x86_64 **UNTESTED**: `nCatImage-0.5.4-UNTESTED-windows-x86_64.exe` — GTK DLL이나 별도 worker EXE를 추출하지 않는 단일 EXE. private pixel 임시 데이터 파일은 생성할 수 있습니다.
- Windows 경고문·의존성 고지 ZIP·빌드/검증 정보·SHA256SUMS를 제공합니다. macOS 배포본은 없으며 기존 Release는 유지합니다.

## 검증과 제한

로컬 Linux Rust 97개(장기 1개 ignored), 실제 GTK metadata/key-signal 3개와 animation/control 8개, Python 배포 7개 및 fmt/Clippy/release build 통과. Windows-target Wine unit 36개(native symlink 1개 ignored), platform/UI 5개와 cross build/system-import 검사 통과.

로컬 전체 desktop 회귀는 xvfb-run 부재로 실행하지 못했습니다. Linux 패키지 desktop/animation/metadata 검사의 최종 결과는 Actions 기록을 따릅니다. key-signal/합성 회귀는 실제 OS 입력·전체 EXIF corpus·IME/접근성 인증이 아닙니다.

> **Windows는 정상 작동/실사용 검증이 완료되지 않은 미서명 UNTESTED 실험판입니다.**
> 최초 native Windows CI의 `private owner/DACL required` 오류는 이번 변경으로 해결하지 않았습니다. 이미지 열기가 실패할 수 있습니다.
> Wine에서도 Job 제한 readback 실패로 보호된 디코딩을 거부합니다. 합성 metadata 창 검사는 이를 우회하거나 정상 이미지 표시 성공으로 계산하지 않습니다.
> native 파일/Job 보안·실제 입력·DPI/접근성·FTP/SFTP 동등성은 여전히 미검증/미완료입니다.

OpenCode 코딩 에이전트를 통한 AI 기반 개발 프로젝트이며 코드 서명된 안정판이 아닙니다.
