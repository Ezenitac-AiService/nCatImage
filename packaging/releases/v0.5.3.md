# nCatImage v0.5.3 — Windows 창 크기 변경 재그리기 수정

> **Windows는 정상 작동/실사용 검증이 완료되지 않은 UNTESTED 실험판입니다.**
> v0.5.2의 최초 native Windows CI는 `private owner/DACL required` 권한 오류로 실패했으며, 이번 릴리스는 그 오류를 수정하지 않습니다. 이미지 열기가 실패할 수 있습니다.
> Wine에서도 Job 제한 검증 실패로 보호된 디코딩을 거부합니다. 보호 우회는 없습니다.

## 수정

- 창 크기 변경·최대화/복원·전체 화면·UI 숨김/표시에서 재그리기와 새 크기 렌더 요청을 연결했습니다.
- 동기 Win32 메시지 재진입 때문에 크기 변경을 놓치던 경로를 별도 메시지로 처리합니다.
- 기존 프레임은 즉시 다시 그리고, 크기 변경이 100ms 동안 안정되면 새 viewport로 backend에 요청합니다. 최소화·종료·동일 크기에서는 불필요한 요청을 피합니다.
- 전체 UI 배경을 다시 칠하고 초기 catalog 완료 후에도 viewport 변경을 재확인합니다.
- `--smoke-resize`로 빈 창의 resize/maximize/restore/fullscreen/UI toggle/minimize/restore와 paint 발생을 검사합니다. 이 검사는 실제 이미지 표시나 native 실사용 검증이 아닙니다.

## 다운로드

- Linux x86_64: `nCatImage-0.5.3-x86_64.AppImage` — Ubuntu 24.04/glibc 2.39 이상 개발 프리뷰.
- Windows x86_64 **UNTESTED**: `nCatImage-0.5.3-UNTESTED-windows-x86_64.exe` — GTK DLL이나 별도 worker EXE를 추출하지 않는 단일 EXE. 같은 EXE의 별도 worker 프로세스와 private pixel 임시 데이터 파일을 사용합니다.
- Windows 경고문·의존성 고지 ZIP·빌드/검증 정보·`SHA256SUMS`를 함께 제공합니다. macOS 배포본은 없습니다.
- v0.5.2와 이전 릴리스는 그대로 유지합니다. GUI/worker는 같은 빌드를 사용하고, 실행 중인 앱은 종료 후 새 파일로 다시 실행하세요.

## 검증·남은 제한

Linux Rust 90개(장기 1개 ignored), Python 배포 검사 7개와 fmt/Clippy/release build를 확인합니다. Windows cross-build/system-DLL import 검사와 Wine의 플랫폼·빈 창·resize·보호 없는 worker 거부 4개를 확인합니다. 패키지 자체의 최종 검사 결과는 Actions 기록을 따릅니다.

Windows NTFS 보안·Job 강제 제한·부모 crash 정리·실제 이미지 표시·입력·DPI/접근성·FTP/SFTP 동등성은 여전히 미검증/미완료입니다. 최초 native 실패 기록: https://github.com/NyarCat/nCatImage/actions/runs/43971418584

OpenCode 코딩 에이전트를 통한 AI 기반 개발 프로젝트입니다. Linux 개발 프리뷰와 미서명 Windows 실험판이며, 코드 서명된 안정판이 아닙니다.
