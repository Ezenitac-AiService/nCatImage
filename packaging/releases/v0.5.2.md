# nCatImage v0.5.2 — Windows 단일 EXE 실험판 포함

> **Windows판은 실제 Windows 환경에서 아직 테스트하지 않은 UNTESTED 실험판입니다.**
> 빌드 성공은 정상 작동 확인을 의미하지 않습니다. 이미지 열기/표시·보안·키보드/마우스·DPI/접근성은 검증 전이며, 사용 중 오류나 기능 미작동이 발생할 수 있습니다.
> 현재 Wine에서는 Job Object 제한을 검증할 수 없어 보호된 이미지 디코딩을 거부합니다. 보호 우회는 포함하지 않았습니다.

## 다운로드

- **Linux x86_64:** `nCatImage-0.5.2-x86_64.AppImage` — Ubuntu 24.04/glibc 2.39 이상 개발 프리뷰.
- **Windows x86_64 · UNTESTED:** `nCatImage-0.5.2-UNTESTED-windows-x86_64.exe` — GTK DLL이나 별도 worker EXE를 추출하지 않는 단일 실행 파일. 같은 EXE의 별도 `--worker` 프로세스를 사용하며 private pixel 임시 데이터 파일은 생성할 수 있습니다.
- Windows 경고문·의존성 고지 ZIP·PE 빌드 정보·`SHA256SUMS`를 함께 제공합니다. 고지 ZIP은 실행에 필요한 DLL 묶음이 아닙니다.
- macOS 배포본은 포함하지 않습니다. 기존 릴리스 파일은 그대로 유지합니다.

## 변경

- Win32 파일/폴더 열기·드롭, 페이지/번호 탐색·RTL, 확대/이동·회전·전체 화면, 애니메이션/프레임 번호 이동·배속 UI를 공통 backend에 연결했습니다.
- Windows UTF-16LE 경로 IPC, file ID/DACL/reparse 검사와 strict Job 보호를 추가했습니다.
- Linux GTK 기능은 유지합니다. GUI/worker wire v4가 함께 변경되므로 구버전 worker와 섞지 마세요.

## 검증과 제한

- 로컬 Linux Rust 90개·실제 GTK 애니메이션/컨트롤 8개·배포 검사 7개 통과, fmt/Clippy/release 빌드 통과.
- Windows cross-build·시스템 DLL import 검사, Wine unit 30개와 플랫폼/빈 창/보호 없는 worker 거부 3개 통과. **이것은 native Windows 시험이 아닙니다.**
- Windows NTFS 공격·Job 메모리 강제 제한·부모 crash 정리·실제 이미지 표시·실제 입력은 미검증입니다. FTP/SFTP 연결과 DPI/접근성 등 Linux판과의 기능 동등성도 미완료입니다.
- 패키지 빌드·회귀 검사의 최종 결과는 해당 Actions 기록을 확인하세요.

OpenCode 코딩 에이전트를 통한 AI 기반 개발 프로젝트이며, 코드 서명된 안정판이 아닙니다. Windows 실행 파일도 Authenticode 서명이 없습니다.
