# nCatImage v0.5.5 — Windows 플로팅 바 프리뷰

- 창 크기 변경, 최대화·복원 시 플로팅 바와 버튼의 배치가 어긋나거나 잔상이 남을 수 있는 경로를 수정했습니다.
- 상·하단 바의 가장자리 표시와 개별 고정 방식은 [ImageViewer](https://github.com/edith2580/ImageViewer)를 참고해 독립 구현했습니다. Tab 메타데이터, 페이지 이동, 확대·축소, 애니메이션 조작은 유지합니다.
- 중첩 대화상자 뒤에 이미지가 ‘읽는 중’으로 멈출 수 있는 문제를 수정했습니다.

이 프리릴리스는 미서명 **Windows x64 단일 EXE**입니다. 실제 Windows 자동 검사는 보안·접근성·실사용 인증이 아닙니다. Linux UI 소스는 변경했지만 이 버전의 Linux 빌드는 제공하지 않습니다. 기존 Linux AppImage는 [v0.5.4](https://github.com/NyarCat/nCatImage/releases/tag/v0.5.4)에서 받을 수 있습니다.
