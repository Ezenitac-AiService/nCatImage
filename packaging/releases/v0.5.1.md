# nCatImage v0.5.1 — 안정적인 프레임 툴바·번호 이동

Linux x86_64 개발 프리뷰 빌드입니다. Windows/macOS는 native 포팅 미완료로 배포본이 없습니다.

- 프레임 전환 때 이전/다음 프레임 버튼이 깜빡이는 원인을 수정했습니다.
- 프레임/전체 수·재생 상태·배속을 타이틀바에서 애니메이션 툴바의 같은 행으로 옮겼습니다.
- 일시정지 중 **프레임 번호(1부터) → 이동 버튼 또는 Enter**로 이동할 수 있습니다.
- 전체 수를 아직 모르는 상태에서 끝보다 큰 번호를 입력하면 마지막 프레임으로 이동합니다. 프레임 전체를 메모리에 쌓지 않으며 긴 파일의 seek는 기존 worker 제한 시간/예산을 적용합니다.
- `,`/`.`/`/`와 0.25×~4× 배속, GIF/AGIF·WebP·APNG 및 ZIP/CBZ 재생은 유지합니다.

Rust 82개·GTK 재생/컨트롤 8개, fmt·Clippy·release 빌드로 검증했습니다. GTK 컨트롤 검사는 scripted signal/property 검사이며 실제 키 입력 주입·전체 코덱/접근성/성능 인증은 아닙니다. 패키지 검사 결과는 Actions 기록을 확인하세요.

AppImage는 Ubuntu 24.04/glibc 2.39 이상 Linux x86_64용입니다. GUI와 worker가 wire v3으로 함께 바뀌므로 구버전 worker와 섞지 마세요. 실행 중인 앱은 종료 후 새 파일로 다시 실행해야 합니다.

OpenCode 코딩 에이전트를 통한 AI 기반 개발 프로젝트이며 코드 서명된 안정판이 아닙니다.
