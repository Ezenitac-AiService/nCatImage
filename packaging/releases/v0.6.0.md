# nCatImage v0.6.0 — 한 장씩 페이지 이동과 서리 유리 UI

- Linux·Windows에서 새 페이지를 읽는 동안 기존 이미지를 유지하며 추가 이동 입력은 저장하지 않습니다. 실패하면 자동으로 건너뛰지 않고 오류를 표시합니다. 다시 누르면 이전·다음 페이지로 이동할 수 있습니다.
- 상단에 페이지 조작, 왼쪽 아래에 애니메이션 조작, 오른쪽 아래에 확대·회전 조작을 배치했습니다. `ⓘ`/`Tab` 메타데이터는 오른쪽 위에, 파일·폴더·주소 열기는 우클릭 메뉴에 있습니다.
- `[` / `]`로 현재 책과 같은 위치에서 이전·다음 이미지 폴더 또는 ZIP/CBZ를 열 수 있습니다.
- Linux Breeze 계열 스크롤바 경고와 데스크톱 회귀 테스트의 창 제목·오버레이 기대값을 수정했습니다.

## 다운로드 및 검증 범위

- **Linux x64 AppImage:** glibc 2.39 이상. 소스 빌드에서 혼합 이미지 폴더와 CBZ 각각 500회 순차 이동, 로딩 중 추가 입력 무시, 손상 페이지 오류 뒤 수동 이동을 확인했습니다. 실제 데스크톱의 모든 GPU·배율·IME·스크린리더 조합을 검증한 것은 아닙니다.
- **Windows x64 `UNTESTED` EXE:** 미서명 교차 빌드. 이 버전의 네이티브 이미지 표시·입력·보안 검증은 미완료이며 알려진 CI 오류 `private owner/DACL required`는 해결하지 않았습니다. 보호를 우회하지 않으며 정식 Windows 배포가 아닙니다.
- macOS 패키지는 없습니다. `SHA256SUMS`와 Windows 고지 파일을 함께 제공합니다.
