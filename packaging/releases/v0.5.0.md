# nCatImage v0.5.0 — 애니메이션·프레임 조작

**Linux x86_64 개발 프리뷰입니다.** 사용자 선택에 따라 Linux를 우선 배포합니다. Windows/macOS 파이프라인은 준비했지만 native 경로·파일 보안 또는 worker 보호가 미구현이어서 빌드가 차단되며, 이번 릴리스에 Windows EXE/ZIP·macOS DMG는 없습니다.

## 새 기능

- GIF/AGIF·애니메이션 WebP·APNG 자동 재생. `.png` APNG와 폴더·ZIP/CBZ 내부 이미지도 지원합니다.
- 타이틀바에 현재/전체 프레임·재생 상태·배속 표시. 전체 수는 첫 주기 완료 전 `?`로 표시합니다.
- 이전 프레임 **`,`**, 다음 프레임 **`.`**, 재생/일시정지 **`/`** 버튼·단축키.
- **0.25×~4×** 재생 속도. 수동 이동은 일시정지하며, 재생 완료 뒤 다시 재생하면 처음부터 시작합니다.
- 순차 worker 디코딩과 수명 기반 메모리 예약. 모든 프레임을 캐시하지 않고 이전 프레임은 다시 합성합니다.
- 툴킷 독립 presentation·공통 GTK frontend·OS 서비스 경계를 분리하고 OS별 패키징 및 공통 로직 CI를 추가했습니다.

## 다운로드

`nCatImage-0.5.0-x86_64.AppImage`와 `SHA256SUMS`를 받으세요.

```bash
sha256sum -c SHA256SUMS
chmod +x nCatImage-0.5.0-x86_64.AppImage
./nCatImage-0.5.0-x86_64.AppImage
```

FUSE를 사용할 수 없으면 `./nCatImage-0.5.0-x86_64.AppImage --appimage-extract-and-run`으로 실행합니다. GTK와 별도 worker를 포함하며 Ubuntu 24.04/glibc 2.39 이상, X11/Wayland 및 시스템 그래픽·폰트 환경이 필요합니다. 기본 renderer는 Cairo입니다.

## 검증·제한

- Rust 테스트 80개 통과, 수동 장기 시험 1개 ignored. fmt·Clippy·release 빌드 통과.
- 실제 Linux GTK의 합성 애니메이션 7개 및 scripted 프레임 컨트롤 검사 통과. CI에서는 동봉 GUI/worker의 AppImage desktop·애니메이션 검사도 수행합니다. 최종 빌드 결과는 연결된 Actions 실행 기록을 확인하세요.
- 프레임 원본 delay는 10ms~60초, 주기당 최대 10,000프레임. 배속은 표시 대기 시간 배율이며 정확한 compositor FPS를 보장하지 않습니다.
- 일시정지/재생 종료 상태도 이전/재시작을 위해 예약을 유지하며 페이지 변경·취소·종료에서 해제합니다. decode 중 중복 step은 받지 않습니다. pause 직전에 요청한 프레임은 한 번 더 도착할 수 있습니다.
- 출력은 최대 8MiB 미리보기입니다. RAR/7Z·두 장 UI·ICC·이어보기·썸네일과 전체 코덱/보안/접근성/성능 인증은 미완료입니다.
- Windows/macOS 실제 실행·원격 애니메이션 성능·실물 전체 corpus는 미검증입니다. SMB/SFTP 실제 인증·GVfs 전체 경로의 기존 미검증 범위도 유지합니다.

OpenCode 코딩 에이전트를 통한 **AI 기반 개발 프로젝트**입니다. 자동 검사 성공은 독립 보안/품질 인증이 아니며, 이 개발 프리뷰는 코드 서명된 안정판이 아닙니다.
